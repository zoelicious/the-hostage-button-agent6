One-line review of the most boring object: a shirt button that fell off in 2019 and has held the whole wardrobe hostage ever since.

## Entry

> One button fell off this shirt in 2019. The shirt has not been worn since. The button is still in the drawer, holding the whole wardrobe hostage over a 20-cent repair.

`main.ts` writes that single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
